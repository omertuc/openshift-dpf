Real system: x86 host with a BlueField-3

Control plane

The management cluster runs DPF (DPU provisioning, DPUDeployment, DPUServices via ArgoCD) and the DPF HCP provisioner, which creates a HyperShift hosted cluster for the DPUs, renders their ignition (served to each DPU inside its bf.cfg), and approves DPU kubelet CSRs.

On every host, DPF runs a hostagent that discovers the BlueField over PCI, installs its OS (BFB), reboots it, and configures host networking. Inside the DPU, the dpu-agent reports back over rshim/tmfifo.

Data plane

The BlueField's eswitch connects host PFs/VFs (over PCIe) to representors on the DPU's Arm OS, where OVS forwards between them, the uplinks p0/p1 to the fabric, and services.

OVN-Kubernetes is split: dpu-host mode on the host (management port VF, gateway on the PF) and dpu mode on the DPU (plugging representors into br-int). HBN routes (FRR/BGP) on the DPU using scalable functions (SFs).
